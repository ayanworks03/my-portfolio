# Ayan Ali — Portfolio

Personal portfolio site: full-stack mobile/web development, React & React Native products, and AI agents/automations.

## Stack

- [Vite](https://vitejs.dev/) + [React](https://react.dev/) + TypeScript
- [GSAP](https://gsap.com/) + ScrollTrigger for scroll-driven reveals
- [Lenis](https://github.com/darkroomengineering/lenis) for smooth scrolling
- [Three.js](https://threejs.org/) for the WebGL background shader (cursor-reactive smoke field)
- Google Fonts: Inter, Poppins, JetBrains Mono, Roboto Flex

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
